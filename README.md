# Peris & David — After the “I Do”

Static post-wedding appreciation website.

## Structure

```text
peris-david-site/
├── index.html
├── README.md
└── images/
    └── wedding/
        ├── README.md
        └── your wedding photos...
```

## Add photos

Open `images/wedding/README.md` for the complete filename list.
In `index.html`, search for `ADD IMAGE HERE` to find every image slot.

## Preview locally

You can simply double-click `index.html`, or use a local server such as VS Code Live Server.
